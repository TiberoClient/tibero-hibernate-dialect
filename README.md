# Tibero Hibernate Dialect

Tibero DB를 **Spring / Hibernate**(JPA)와 함께 사용하기 위한 Hibernate Dialect 구현입니다.  
Spring Boot JPA, Spring Data JPA 등에서 Tibero를 데이터베이스로 사용할 때 이 dialect를 설정하면 됩니다.
